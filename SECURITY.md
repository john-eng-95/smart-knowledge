# Security Policy

## Supported Versions

Security fixes are provided for the latest version on the default branch.

## Reporting a Vulnerability

Do not publish vulnerability details in a public issue. Use GitHub's private
vulnerability reporting for this repository. Include affected versions,
reproduction steps, and potential impact. Do not include live credentials or
personal data in a report.

The example Compose credentials are for isolated local development only. This
project has not been security-audited and must not be exposed to untrusted
networks without a separate security review.
